# Proyecto Evaluación 2 - Software de Geolocalización

## Descripción del Proyecto
Script en Python desarrollado dentro del entorno DEVASC para interactuar con la API de Graphhopper Directions, permitiendo obtener rutas y narrativas de viaje en español con formateo a dos decimales.

## Instrucciones de Ejecución
1. Ejecute el script en Python desde la terminal:
   python graphhopper_parse-json_7.py
2. Para finalizar la ejecución, ingrese "s" o "salir" cuando el programa lo solicite.
